### **To install the skill:**
Attach this skill to Claude code (or you can copy it), with prompt:  

[[Synced Vault Skill content]]
'Install this is skill globally'

### **To run the skill:**  
Then open Obsidian, install the Terminal Extension on Obsidian, open Claude Code in Obsidian, and run the skill  

'Run synced-vault skill in this directory'
